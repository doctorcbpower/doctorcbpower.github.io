Software

I develop and maintain scientific software as part of my research. Some of it is closely tied to particular projects; some has grown into more general tools for working with simulations, merger trees, and astrophysical populations. I release most of the software openly, both because it makes the research easier to reproduce and because useful tools tend to outlive the particular project for which they were written.

Software

foraois

A Python implementation of extended Press–Schechter merger trees for dark matter halo populations. It supports different collapse barriers and several dark matter models, including CDM, WDM and fuzzy dark matter, and is designed to make the assumptions entering the merger-tree calculation explicit.

github.com/solas-sims/foraois

Ashvini

A Python galaxy formation and evolution model that takes dark matter halo merger histories as input and follows the evolution of gas, stars and dust. I use it to explore how assumptions about galaxy formation interact with the underlying dark matter model.

github.com/doctorcbpower/Ashvini

realta

A modular stellar and binary population-synthesis framework, developed from the Monte Carlo model used in my earlier work on high-mass X-ray binaries. The aim is to provide a transparent and reproducible way of following stellar and binary populations from their formation through evolution, compact-object formation and observable properties.

github.com/doctorcbpower/realta

imbas

A rendering engine for turning astrophysical simulation snapshots into high-fidelity images. It reads Gadget, SWIFT and Arepo snapshots and supports particle projection, SPH smoothing, animations and parallel rendering.

github.com/doctorcbpower/imbas_renderer

AnalysisTools

A Python toolkit for working with particle-based simulation data, designed for cosmological simulations and galaxy formation studies.

github.com/doctorcbpower/AnalysisTools

Collaborative projects

SOLAS

SOLAS is a collaborative simulation project for modelling astrophysical transients and their observable signatures. The project includes a modified version of AREPO and associated simulation infrastructure.

github.com/solas-sims/arepo_solas

The SOLAS project also maintains a fork of Grackle, the chemistry and radiative-cooling library used by a number of astrophysical simulation codes.

Supporting software

There are also many smaller scripts and utilities for processing simulations, generating initial conditions, analysing halo catalogues and producing derived quantities. These are generally less polished than the software above, but remain available on GitHub.

Why I write software

For me, software is part of the scientific method rather than something separate from the research. A useful code should make the assumptions of a calculation visible, allow different physical models to be compared, and make it possible to reproduce or extend an experiment. I also like building tools that remain useful after the paper that motivated them has been published.
